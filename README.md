# TechGadgetsDB
Base de datos completa desarrollada para una empresa ficticia de e-commerce llamada **TechGadgets**.  
Incluye tablas, datos de prueba, vistas, transacciones y manejo de locks.  
Proyecto académico para demostración de habilidades en SQL, diseño de bases de datos y buenas prácticas.

## Contenido
- Script completo DDL + DML
- Ejemplos de consultas avanzadas (JOIN, GROUP BY, HAVING)
- Implementación de transacciones ACID
- Manejo de niveles de aislamiento y locks
- Datos de prueba realistas para análisis y reportes

## Tecnologías
- SQL Server
- SQL ANSI
- Modelado relacional
